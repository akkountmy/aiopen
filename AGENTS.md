# DSH.OPEN.WEB — правила работы

Node-сервис (без сборки): `server.mjs` + ванильный SPA в `public/`. Прод — Amvera
(`https://dshopen-vladimir00177.msk1.amvera.tech`). Выкладка — **заливка файлов**
(`scripts/deploy-amvera.mjs push <файлы>` → `build` → `wait`); `git push` — это версия
в репозитории, а не деплой, Amvera из GitHub НЕ собирает. Презентации собирает
`src/doc/deck.mjs` → headless-Chromium PDF.

## Обязательный цикл правки

1. **Сначала `git status`.** Грязная рабочая копия — главная причина дорогих сессий: чужие
   правки сидят в тех же файлах, а незакоммиченное мешает отделить своё. Если правите не своё
   и дерево грязное — не сшивайте hunks из рабочего дерева. Либо согласуйте коммит всей пачки,
   либо применяйте правку к `git show HEAD:<файл>` в `tmp/` и кладите результат в индекс
   (`git hash-object -w` + `git update-index --cacheinfo`).
2. **Тест раньше правки.** Сначала воспроизведи дефект локально (`test/*.mjs` или короткий скрипт
   в `tmp/`), потом меняй код. Живой сервис — только для финального подтверждения, один раз.
3. **Одна пересборка на пачку правок.** Правишь несколько файлов — выкладываешь один раз.
   Запрещено деплоить после каждого исправления: сборка Amvera идёт 2–6 минут.
4. **Ожидание сборки — только** `node scripts/deploy-amvera.mjs wait` (смотрит `buildStatus`/
   `buildStatusTime`). Не поллить руками, не ждать `status` (он остаётся `RUNNING`).
5. **Деплой подтверждается фактом, а не сообщением сборки:** `GET /api/health` → 200, маркер
   в `/styles.css` или `/app.js`, `?v=` в `/index.html` сменился. На вопрос «задеплоил всё?»
   отвечает `node scripts/deploy-diff.mjs --exit-1`, а не память.
6. **Живая проверка презентации — одной командой** `node scripts/check-deck-live.mjs "просьба"`.
   Новых CDP-проб не писать. Браузер — только для визуального вида, и тогда один прогон,
   один снимок, один просмотр.
7. **Живые UI-проверки — на уже запущенном `:3131`**, логин/пароль из хранилища (см. ниже).
   Свой сервер и чистую базу поднимать только если без этого дефект не воспроизводится; данные
   в `tmp/`, за собой убрать. Новый порт — не способ изоляции по умолчанию.
8. **Тесты — только затронутые наборы** (`node test/deck.mjs`, `node scripts/check.mjs --only ui-support`).
   Полный прогон — перед финальной сборкой, не после каждой правки.
9. **Тест SPA — через DOM, не через вызовы функций:** `public/app.js` — ES-модуль, его функции
   не попадают в `window`; проверяйте атрибуты (`#userChip.dataset.support`) и видимое
   поведение в `page.evaluate`, а не `applySupportBadge(...)` напрямую.
10. **Правка UTF-8 — только инструментами `edit`/`write`.** `-replace`/`Set-Content` в PowerShell
    по русскому тексту запрещены: был случай порчи файла и полкруга на поиск несуществующего баг.
11. **Черновики и артефакты — только в `tmp/`** (в `.gitignore`). В корне репозитория ничего
    не создавать: дампы вида `.skill-matrix-*.json` сразу туда или в `.gitignore`.
12. **Контекст: `grep` + чтение нужных строк**, а не перечитывание файлов целиком ради фона.
    Дампы логов и скриншоты смотреть точечно, не вываливать целиком в ответ.

## Команды

```powershell
node test/deck.mjs                       # раскладка/подгонка деки
node test/docs.mjs                       # документы + бюджет промпта (падает, если промпт больше предела)
node scripts/check.mjs --only ui-support # точечный прогон без живых наборов
node scripts/check-deck-live.mjs "текст" # сквозная живая проверка деки (сам убирает проект)
node scripts/deploy-diff.mjs --exit-1    # гейт «всё выложено?»: код 1, если есть невыложенное
node scripts/deploy-amvera.mjs push public/app.js public/styles.css   # пачка — одной заливкой
node scripts/deploy-amvera.mjs build
node scripts/deploy-amvera.mjs wait
node scripts/deploy-amvera.mjs status    # смотреть через -Last, не First (EPIPE = не ошибка)
```

Секреты прода: `& "$env:USERPROFILE\.dsh\secrets\_vault.ps1" get dshow-admin -Field login|password`.

## Где что живёт

`server.mjs` — HTTP и потоковые ответы · `public/app.js`, `public/styles.css` — SPA ·
`src/tools.mjs` — инструменты модели · `src/doc/deck.mjs` — дека и замер раскладки ·
`src/prompt.mjs` — системный промпт · `assets/deck/` — CSS деки · `test/` — наборы проверок ·
`scripts/` — деплой и живые пробы.

## Запреты

- Геометрию `assets/deck/deck.css` не трогать: новые правила — в `assets/deck/deck-extra.css`.
- Деку не сжимать: не уменьшать шрифт, не уплотнять `rows`, не выбрасывать содержимое.
  Порядок подгонки: лид → деление слайда → сноска → миниатюры обложки.
- В `deck.mjs` не читать диск: дека — функция от спека; файлы в base64 превращает `src/tools.mjs`.
- На живом сервисе удалять только свои проекты «Проба …» и сразу за собой.
