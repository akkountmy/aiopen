# Excel-книга (.xlsx)

Итог навыка — файл, который открывается в Excel, пересчитывается сам, читается с одного взгляда и не разваливается, когда пользователь поменяет одну цифру.

## Когда открывать
«Сделай эксель», «таблицу», «смету», «финмодель», «выгрузку», «расчёт в Excel», «сводную», «дашборд», «реестр». Если нужны только цифры в ответе — хватит текста с таблицей; если файл будут править и считать — это книга.

## Инструмент
`create_excel({ path, sheets })`, лист:
- `name` — до 31 символа, без `[]:*?/\`;
- `title` — заголовок над таблицей (объединённая первая строка);
- `columns[]` — `header`, `width`, `numFmt`, `numeric`, `align`, `wrap`;
- `rows[][]` — числа числами, формулы строкой с `=` (`"=SUM(C5:C12)"`, `"=C5/B5"`);
- `totalRow: true` — последняя строка как «Итого»;
- `freezeColumns`, `autoFilter`, `note`;
- `conditional[]` — `{ range: "E5:E12", from, to }` цветовая шкала;
- `chart` — `{ type, title, categoriesColumn, valueColumns, position: "G2" }`.

Одна книга — один вызов `create_excel`: меньше вызовов, меньше рассинхрона между листами. Выгрузка на 50 000+ строк через `create_excel` не собирается — см. «Большие данные».

## Как устроить книгу, которую не стыдно отдать
1. **Лист «Итоги»** — 5–9 ключевых чисел, подписи с периодом и единицей, один вывод текстом внизу.
2. **Лист «Расчёт»** — формулы, а не готовые числа; одинаковые формулы по всей колонке.
3. **Лист «Данные»** (если есть исходник) — сырые строки как есть, без пересчётов и без итоговых строк.
4. **Лист «Допущения»** — ставки, курсы, дата выгрузки, источники; всё, что меняется, живёт здесь, а формулы ссылаются на эти ячейки.
5. **Лист «Проверки»** (для расчётов и моделей) — 2–4 контрольные формулы, каждая даёт 0 при корректных данных.

Порядок листов = порядок чтения: сначала вывод, потом расчёт, потом сырьё.

## Формулы и форматы
- Итоги — `SUM`, средние — `AVERAGE`/`AVERAGEIFS`, рост — `=C5/B5-1` с форматом `0,0%`.
- Деньги — `#,##0`, копейки — `#,##0.00`, проценты — `0,0%`, даты — `dd.mm.yyyy`, ID — текстом.
- Не считай в голове и не пиши «итого» числом: Excel должен пересчитать сам.
- Деление проверяй: `=IFERROR(C5/B5,0)`, если в знаменателе возможен ноль; поиск — `IFERROR(XLOOKUP(...),0)`.
- Условные агрегаты — `SUMIFS`/`COUNTIFS` по колонке-критерию, а не заранее посчитанные суммы.
- Формулы одного столбца одинаковой структуры, ссылки — относительные там, где нужна протяжка.
- Проценты считай от одного и того же базы: если база в отдельной ячейке — на неё и ссылайся (`$B$2`), иначе протяжка уедет.

## Большие данные
- Excel держит 1 048 576 строк на лист, но книга с десятками тысяч тяжёлых строк начинает тормозить. Больше ~20 000 строк — вынеси сырьё в отдельный `.csv` (или лист «Данные» без оформления), а в книге оставь агрегаты.
- Считай большие выгрузки инструментом `analyze_data` (`mode: "profile"` → `mode: "query"` с `filters`/`groupBy`/`metrics`/`sort`). Если нужна логика, которой там нет, — пиши формулы прямо в книге через `create_excel` (`СУММЕСЛИМН`, `СЧЁТЕСЛИМН` на листе «Сводка»), чтобы человек видел расчёт; результат `analyze_data` переноси в `create_excel` как значения.
- Никогда не пересчитывай 30 000 строк «в уме» и не вставляй их текстом в книгу: сначала агрегат, потом книга.
- Сводную (pivot) `create_excel` не строит. Если просят «сводную» — сделай лист-сводку на `SUMIFS`/`COUNTIFS` по категориям и назови его «Сводка», а не притворяйся, что это живая сводная таблица.

## Проверка перед сдачей
1. `create_excel` возвращает «Проверка файла: …». «ОШИБКИ» — не отдавай файл, исправь и пересоздай.
2. Замечание «лист пустой» — в `rows` не попало ни строки.
3. Замечание «пустых ячеек N из M» — строки короче шапки либо в колонке пропуски.
4. `#REF!`, `#DIV/0!`, `#NAME?`, `#VALUE!` в результате — дефект: исправь формулу и пересоздай файл.
5. Итог формулы проверь независимо (через `calculate`, `check_document` или пересчёт на листе «Проверки») — не доверяй тому, что «должно сойтись».
6. Повторно: `check_document({ path })` — структура, листы, формулы.

## Чего не делать
- Не сливай всю книгу в один лист: 200 строк и 14 колонок читаются плохо, а фильтр по ним не работает.
- Не делай шапку цветной радугой: один акцентный цвет, остальное нейтральное.
- Не пиши числа текстом («1 250 000 ₸» строкой) — ломается сортировка и суммы.
- Не объединяй ячейки внутри таблицы данных — ломаются фильтр, сортировка и `SUM`.
- Не оставляй пустые строки и служебные колонки внутри диапазона: `SUM` и автофильтр обрываются на разрыве.
- Не строй диаграмму по вычисленным вручную числам, только по строкам листа.
- Не оставляй `Sheet1` и рабочие листы-черновики: пользователь увидит их первыми.
- Не выдавай готовые значения там, где пользователь ждёт формулу: книгу будут править.

`Смета проекта.xlsx`, `Финмодель 2026.xlsx`, `Сводка продаж.xlsx`. Коротко, по делу, расширение видно. Для анализа сырых выгрузок есть отдельный навык — `data-analysis`.
