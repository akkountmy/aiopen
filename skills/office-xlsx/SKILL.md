# Excel-книга (.xlsx)

## Когда открывать
«Сделай эксель», «таблицу», «смету», «финмодель», «выгрузку», «расчёт в Excel»,
«дашборд». Если нужен только текст с цифрами — хватит ответа в чате.

## Инструмент
`create_excel({ path, sheets })`, лист:
- `name` — до 31 символа, без `[]:*?/\`;
- `title` — заголовок над таблицей;
- `columns[]` — `header`, `width`, `numFmt`, `numeric`, `align`, `wrap`;
- `rows[][]` — числа числами, формулы строкой с `=` (`"=SUM(C5:C12)"`, `"=C5/B5"`);
- `totalRow: true` — последняя строка как «Итого»;
- `freezeColumns`, `autoFilter`, `note`;
- `conditional[]` — `{ range: "E5:E12", from, to }` цветовая шкала;
- `chart` — `{ type, title, categoriesColumn, valueColumns, position: "G2" }`.

## Как устроить книгу, которую не стыдно отдать
1. **Лист «Итоги»** — 5–9 ключевых чисел и один вывод текстом.
2. **Лист «Расчёт»** — формулы, а не готовые числа.
3. **Лист «Данные»** (если есть исходник) — сырые строки как есть.
4. **Лист «Допущения»** — ставки, курсы, дата, источники; всё, что меняется, живёт здесь, а формулы ссылаются на эти ячейки.

## Формулы и форматы
- Итоги — `SUM`, средние — `AVERAGE`, рост — `=C5/B5-1` с форматом `0,0%`.
- Деньги — `#,##0`, проценты — `0,0%`, даты — `dd.mm.yyyy`.
- Не считай в голове и не пиши «итого» числом: Excel должен пересчитать сам.
- Все формулы одного столбца одинаковой структуры — иначе ошибки не находятся.
- Деление проверяй: `=IFERROR(C5/B5,0)`, когда в знаменателе может быть ноль.

## Проверка перед сдачей
1. `create_excel` возвращает «Проверка файла: …». «ОШИБКИ» — не отдавай файл.
2. Замечание «лист пустой» — значит в `rows` не попало ни строки.
3. Замечание «пустых ячеек N из M» — строки короче шапки либо в колонке пропуски.
4. `#REF!`, `#DIV/0!`, `#NAME?` в результате — это дефект: исправь формулу и пересоздай.
5. Повторно: `check_document({ path })`.

## Чего не делать
- Не сливай всю книгу в один лист: 200 строк и 14 колонок читаются плохо.
- Не делай шапку цветной радугой: один акцентный цвет, остальное нейтральное.
- Не пиши числа текстом («1 250 000 ₸» строкой) — ломается сортировка и суммы.
- Не строй диаграмму по вычисленным вручную числам, только по строкам листа.

## Имя файла
`Смета проекта.xlsx`, `Финмодель 2026.xlsx`. Коротко и с расширением.
