# Интернет через DeepSeek Search / Fetch

`web_search` ходит в DeepSeek Search: возвращает заголовок, ссылку, сниппет, дату и авторитет источника (0–4). `fetch_url` для обычного GET идёт в DeepSeek Fetch и отдаёт страницу чистым Markdown без браузера; POST, свои заголовки и сайты, которые DeepSeek не взял, загружаются прежним путём.

## Когда вызывать самому

- Свежие события, курсы, цены, погода, релизы, вакансии, «что нового».
- Проверка факта, цифры, даты, имени — если память могла устареть.
- Нужен первоисточник: официальный сайт, документация, отчёт, регулятор.
- Пользователь просит «поищи», «найди», «проверь», «дай ссылки», «актуально на сегодня».
- Не вызывай для правки файла, кода и расчётов по уже известным цифрам.

## Как искать

1. **2–4 формулировки за один вызов** через `queries`: по-русски и по-английски, официальное название и бытовое. Это дешевле, чем четыре отдельных вызова.
2. **Сначала выдача, потом страница.** Сниппета хватает выбрать источник; `fetch_url` — когда нужна точная цифра, цитата или методика.
3. **Дата и авторитет важнее позиции.** Для цифр бери авторитет 3–4 и смотри дату; агрегатор — только наводка.
4. **Операторы** прямо в запросе: `site:`, `-site:`, `"точная фраза"`, `filetype:pdf`.
5. **Не выдумывай при пустой выдаче.** Скажи «не нашлось» и что именно искал; попробуй другой угол, но не повторяй один и тот же запрос больше двух раз.
6. **Ссылка — в ответ.** Для каждого числа или цитаты указывай источник и дату публикации.

## Ограничения

- Лимит — около 5 запросов в секунду на аккаунт; не запускай десятки параллельных поисков.
- `fetch_url` не умеет авторизацию и POST; для API нужен прямой вызов с заголовками.
- Если сайт отдал пусто или «включите JavaScript», используй `fetch_url` без DeepSeek (он сам переключится) или `scrape_page`.
- Платно: около $0.75 за 1000 успешных запросов Search или Fetch; не делай поиск ради поиска.
