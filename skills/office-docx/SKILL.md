# Word-документ (.docx)

## Когда открывать
Просят «вордовский файл», «документ Word», отчёт, договор, коммерческое предложение,
служебную записку, регламент. Если просят PDF — это навык `pdf-report`, не этот.

## Инструмент
`create_word({ path, title, cover, toc, headerText, footerText, pageNumbers, sections })`

Поля раздела `sections[]`:
- `heading` — заголовок раздела (нумеруй в тексте: «1. Рынок», «2. Финансы»);
- `paragraphs` — абзацы обычным текстом, 2–5 предложений каждый;
- `bullets` — короткие пункты без точек в конце;
- `kpi` — строка показателей `[{ value: "128 млрд ₸", label: "объём рынка 2025" }]` (2–4 штуки, не больше);
- `table` — `{ headers: [...], rows: [[...], [...]] }`;
- `chart` — настоящая диаграмма Word (см. ниже), `charts` — несколько подряд;
- `image` — картинка из файлов проекта, `images` — несколько подряд;
- `note` — сноска под разделом (источник, допущение).

## Диаграммы и картинки
Диаграмма в Word — живой объект: в Word работают «Изменить данные», смена типа и цветов.
Внутрь файла кладётся книга данных, поэтому диаграмма редактируется без внешних файлов.

```json
"chart": {
  "type": "column",
  "title": "Выручка по кварталам, млн ₽",
  "categories": ["Q1", "Q2", "Q3", "Q4"],
  "series": [
    { "name": "2025", "values": [86.4, 92.1, 98.7, 110.2] },
    { "name": "2026", "values": [104.2, 112.8, 121.5, 138.4] }
  ]
}
```

- `type`: `column` (столбцы), `bar` (горизонтальные полосы), `line` (динамика),
  `pie` / `doughnut` (доли одного периода), `area` (площади).
- `categories` — подписи оси X, их число равно длине `values`; без них диаграмма бессмысленна.
- `values` — числа, а не строки; не подставляй «12,4» — только `12.4`.
- Один ряд — легенда не нужна, два и больше — обязательны понятные имена рядов.
- `width` / `height` в пикселях задавай только если нужен нестандартный размер;
  по умолчанию диаграмма занимает ширину полей страницы.

Картинка берётся **только из файлов проекта**:

```json
"images": [{ "path": "assets/logo.png", "caption": "Логотип проекта", "width": 8 }]
```

- Поддерживаются PNG, JPEG, GIF, BMP; размер файла до 12 МБ. WebP и SVG Word не покажет.
- `path` — путь относительно корня проекта, как в `list_files`; не придумывай путь.
  Если файла нет, инструмент вернёт ошибку «Файл изображения не найден» — найди файл и повтори.
- `width` в сантиметрах; по умолчанию — по ширине полей, но не больше натурального размера.
- `caption` — подпись под картинкой. Схема или скриншот без подписи в отчёте — дефект.

Обложку (`cover: true`) ставь только для документа от 4 страниц. `toc: true` — от 3 разделов.
`headerText` — короткое название документа, `footerText` — «Источник: …» или пусто.

## Эталонная структура отчёта
1. Резюме (3–6 пунктов, главный вывод первым).
2. Контекст и данные (что известно, чего нет — честно).
3. Основная часть: таблицы + пояснение к каждой таблице одним абзацем.
4. Риски и ограничения.
5. Выводы и рекомендации (что делать, в каком порядке).
6. Источники (список ссылок или названий документов).

## Правила, которые чаще всего нарушают
- Заголовок раздела не повторяет первый абзац под ним.
- В таблице не больше 6 столбцов — иначе Word сожмёт её до нечитаемого.
- Числа с единицами измерения и одинаковой точностью во всей таблице (`12,4 %`, не `12.4`).
- Никаких выдуманных цифр: если данных нет — пиши «нет данных» и что нужно уточнить.
- Не вставляй разметку markdown (`**`, `#`) — в Word она выглядит мусором.
- Каждая пустая ячейка таблицы — дефект: либо заполни, либо убери столбец.

## Проверка перед сдачей
1. `create_word` сам возвращает строку «Проверка файла: …».
2. Если в ней «ОШИБКИ» — разберись почему (нет текста, битые ссылки пакета) и пересоздай файл, не отдавай пользователю.
3. Если «замечания» — поправь за один проход (пустые ячейки, нет настроек страницы).
4. Для ручной правки или повторной проверки: `check_document({ path })`.

## Частые причины отказа
| Симптом | Причина | Что делать |
|---|---|---|
| «нет ни одного абзаца» | всё содержимое ушло в `table`, а текста нет | добавь абзац-пояснение в раздел |
| «пустых ячеек N» | строки короче шапки | выровняй длину строк по числу столбцов |
| «битые ссылки внутри пакета» | повторное редактирование файла вручную | пересоздай через `create_word` |
| Документ не открывается в Word | файл перезаписан через `write_file` | .docx собирает только `create_word` |
| «Файл изображения не найден» | путь придуман или файл вне проекта | найди файл через `list_files`, повтори с верным путём |
| «не PNG, JPEG, GIF или BMP» | WebP/SVG/иной формат | конвертируй в PNG (например, через `run_python`) или возьми другой файл |
| «части диаграмм есть, но в тексте нет ни одной» | файл собирался не через `create_word` | пересоздай документ через `create_word` |

## Имя файла
Короткое, понятное, с расширением: `Отчёт по рынку.docx`, `Договор НД.docx`. Не
`report_final_v2_new.docx`.
