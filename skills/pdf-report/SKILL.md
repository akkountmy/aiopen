# PDF-документ (.pdf)

## Когда открывать
«Сделай PDF», «в пдф», «отчёт в PDF», «презентацию в PDF», «счёт», «договор на печать».
Если формат не оговорён и нужен редактируемый файл — это Word или Excel.

## Инструмент
`create_pdf({ path, layout, title, subtitle, kicker, author, date, footerText, cover, sections })`

- `layout: "document"` — A4-документ: `sections[]` с `heading`, `paragraphs`, `bullets`,
  `kpi`, `table`, `note`. Колонтитул и нумерация страниц ставятся автоматически.
- `layout: "slides"` — широкоформатные страницы-слайды: `slides[]` с `title`, `bullets`,
  `table`, `chart`, `note`.
- `cover: true` — титульная страница. Для одностраничника не нужна.

## Правила печатного документа
- Поля и шрифт заданы шаблоном; своя «ручная» вёрстка не нужна — управляй структурой.
- Раздел начинается с заголовка и содержит хотя бы один абзац текста.
- Таблица в PDF — не больше 5 столбцов; больше — переноси часть в приложение.
- «Источник: …» ставь в `note` у раздела, а не в колонтитул.
- Слайд-режим используй, когда PDF — это именно раздатка презентации.
- Никаких ссылок `file:///`, `localhost` и «скачайте по ссылке»: файл открывается во вкладке браузера.

## Проверка перед сдачей
1. `create_pdf` возвращает «Проверка файла: …» с числом страниц и шрифтов.
2. «в PDF нет встроенных шрифтов» — текст не отобразится: пересоздай файл.
3. «в PDF нет страниц» — пустой документ, причина в отсутствии `sections`/`slides`.
4. Сверь число страниц со смыслом: 1 страница для отчёта из 6 разделов — ошибка.
5. Повторно: `check_document({ path })`.

## Имя файла
`Отчёт по рынку.pdf`, `Счёт 128.pdf`, `Питч-дек.pdf`.
