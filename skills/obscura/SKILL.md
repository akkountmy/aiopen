# Obscura: страницы, которые не отдаются обычной загрузкой

Obscura (h4ckf0r0day/obscura, Rust, Apache-2.0) — браузер без Chromium: настоящий
V8, stealth-отпечаток и блокировка трекеров при весе в десятки мегабайт. В этом
приложении она уже встроена как **запасной движок загрузки**, отдельной
установки и ключей не требует.

## Когда звать

`engine: "auto"` стоит по умолчанию во всех инструментах загрузки: сначала
обычный HTTP, и только если пришла заглушка (статус 4xx/5xx, признаки капчи,
меньше 400 символов текста) — страница повторно берётся obscura. То есть часто
ничего делать не нужно. Звать явно стоит, когда:

- ответ содержит «проверка браузера», `fab_chlg`, `cf_chl`, «Just a moment», капчу;
- SPA отдала пустой каркас и `render` недоступен (в облаке Chromium может не быть);
- сайт режет серверные запросы по отпечатку TLS;
- нужные данные видны только после JavaScript, а Playwright недоступен.

## Как вызвать

```
scrape_page { "url": "https://site.ru", "engine": "obscura", "format": "markdown" }
read_page   { "url": "https://site.ru", "engine": "obscura" }
fetch_url   { "url": "https://site.ru", "engine": "obscura" }
```

- `engine`: `auto` (по умолчанию) · `http` (только HTTP, без браузера) ·
  `obscura` (сразу браузер) · у `scrape_page` ещё `browser` = `render: true`.
- `proxy`: `http://host:port` или `socks5://host:port` — когда сайт недоступен по
  сети или держит капчу по IP. Прокси в этом приложении не настроен по умолчанию.
- `wait_ms` (до 20000) — если контент появляется с задержкой.

Ответ честно говорит, чем загружено: в `meta.engine` — `obscura`/`http`/
`playwright`, а в тексте строка `[Загружено браузером obscura…]`. Если сайт всё
равно отдал проверку, в тексте будет предупреждение: это заглушка, а не данные —
не пересказывай её как факты.

## Порядок выбора

1. `web_search` — найти источники.
2. `fetch_url` — быстрый текст одной страницы (DeepSeek Fetch → HTTP → obscura).
3. `read_page` — статья целиком, оглавление, таблицы, ссылки.
4. `scrape_page` — Markdown, поля по CSS-селекторам, конкретные цены и даты.
5. `scrape_page` с `engine: "obscura"` — если предыдущие отдали заглушку.
6. `scrape_page` с `render: true` / `engine: "browser"` — интерактив и скриншоты
   (в облаке может быть недоступно).
7. `fetch_many` / `crawl` — обход нескольких страниц (внутри тоже работает auto).

## Состояние и настройка

- `/api/health` (публичный) отдаёт блок `stealth`: `enabled`, `ready`, `binary`,
  `version`, `installDir`. `ready: false` — бинарник ещё не скачан.
- `/api/stealth` (после входа): `GET` — статус, `POST` — установить сейчас.
- Первый запуск скачивает релиз v0.2.5 (75 МБ) в `DATA_DIR/vendor/obscura-0.2.5`
  (в облаке это постоянный том `/data`), проверяет SHA-256 и распаковывает своим
  парсером tar — `tar` в образе не нужен. Скачивание идёт один раз, в фоне при
  старте сервиса.
- `DSHOW_OBSCURA=off` — выключить движок целиком; `OBSCURA_BIN=/path/obscura` —
  взять свой бинарник; `DSHOW_OBSCURA_SHA256` — своя контрольная сумма.
- Ставится только `linux-x64` (в облаке — да). Локально Windows/macOS: положи
  бинарник сам и укажи `OBSCURA_BIN`.

## Границы и честность

- Только публичные страницы. Нет обхода авторизации, платного доступа, решения
  капчи «за человека» и подделки чужой сессии.
- Внутренние и приватные адреса (localhost, 10.x, 169.254.x, метаданные хостинга)
  блокируются до запроса — это защита самого сервиса, а не пожелание.
- Stealth обходит проверку отпечатка TLS/JS, но **не** репутацию IP: при капче
  «по IP» нужен `proxy`, иначе честный ответ — «сайт закрыт капчей».
- Ограничения запроса: страница до 12 МБ, потолок процесса 40 с, stdout 16 МБ.
- robots.txt и условия сайта уважаем: не долбим один сайт десятками запросов.

## Если не получилось

| Что видно | Что делать |
|---|---|
| `[Obscura недоступна: …]` | нажать `POST /api/stealth`, проверить место на диске и сеть до GitHub |
| «неверный размер архива» / «сумма не совпала» | сеть отдала обрезанный файл: повторить установку, при повторе — проверить прокси |
| заглушка капчи с `obscura` | блокировка по IP: `proxy`, VPN, или брать данные из другого источника |
| `Сайт ответил 5xx` | это не анти-бот; сайт лежит — попробовать позже или взять копию в веб-архиве |
| `Страница слишком большая` | брать конкретную страницу/раздел, а не корень каталога |
