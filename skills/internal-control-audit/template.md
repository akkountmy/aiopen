# Внутренний контроль: матрица и отчёт о проверке

Две части: матрица рисков и контролей (заполняет владелец процесса вместе с риском) и отчёт о проверке (заполняет внутренний аудит). Формулировки — без обвинений в адрес сотрудников.

## Часть 1. Матрица рисков и контролей

| № | Процесс | Риск | Влияние | Контроль | Тип | Кто | Когда | Доказательство | Ключевой |
|---|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  | превентивный / детективный, ручной / автоматический |  |  |  | да / нет |

Проверка матрицы перед тестированием:

- у каждого существенного риска есть хотя бы один контроль;
- у контроля один владелец, а не «отдел»;
- есть доказательство, которое можно приложить к делу;
- нет одного сотрудника и на подготовке, и на утверждении, и на приёмке.

## Часть 6. Вывод аудита

Одна страница: что проверяли, что в целом работает, что не работает и чем это грозит, какие три действия нужны в первую очередь. Уровень уверенности и границы: «вывод сделан по выборке 25 из 1 240 случаев за IV квартал; на другие периоды не распространяется».
