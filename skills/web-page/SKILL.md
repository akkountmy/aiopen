# Веб-страница (.html)

## Когда открывать
«Сделай лендинг», «страницу», «одностраничный сайт», «интерактивный отчёт»,
«дашборд на HTML». Файл `.html` открывается у пользователя во вкладке браузера.

## Что уже есть — не изобретать заново
| Что | Чем брать |
| --- | --- |
| Каркас страницы: hero, 2–4 числа, карточки, таблица, финал, подвал, адаптив, плашка ошибок | `page_template` |
| Живая проверка: снимки 390/768/1440 px и машинный отчёт | `check_page` |
| Файлы страницы в проекте | `write_file` / `append_file` (первая часть до ~8 КБ) |

Собери страницу из `page_template` и замени содержимое. Внешние CSS/JS не нужны:
всё в одном файле.

## Анатомия страницы, которая выглядит дорого
1. `<!doctype html>`, `lang="ru"`, `meta viewport`, `charset`, `<title>` — утверждение.
2. Hero: заголовок-утверждение с числом, подзаголовок в одну строку, одно действие.
3. 3–6 смысловых блоков: одна мысль + визуальный акцент (карточки, таблица, цифры).
4. Один блок чисел: 2–4 KPI с единицей и периодом.
5. Финал: вывод и следующий шаг.
6. Подвал: кто, когда, на каких данных.

## Стиль
- CSS-переменные в `:root`, один акцентный цвет, системный шрифт, отступы кратны 8 px.
- `clamp()` для заголовков, `auto-fit/minmax` для сеток — вёрстка сама подстраивается.
- Контраст текста не ниже 4.5:1, тап-цели от 44 px, состояния `:hover` и `:focus-visible`.
- Не больше двух весов шрифта и одного акцента.

## Границы, которые нельзя переступать
- Один файл: стили и скрипты внутри, внешних CSS/JS нет.
- Никаких CDN, Google Fonts и `fetch` к внешним API — страница обязана работать офлайн.
- Графики — inline SVG или canvas; 3D — только через навык `three-js`.
- Интерактив — пара строк `addEventListener` + `classList`, без фреймворков.
- Цифры, имена и даты только из данных пользователя; чего нет — «нет данных».

## Проверка перед сдачей
1. `check_page({ url: "Страница.html" })` — по умолчанию три ширины.
2. Смотри в отчёте: горизонтальная прокрутка на 390 px, ошибки консоли, битые
   запросы, внешние запросы, картинки без alt, наличие h1.
3. Снимки открывай и смотри глазами (390 px первым: там ломается чаще всего).
4. Замечания чини и проверяй заново, пока отчёт не станет чистым.

Если браузера в окружении нет (облако без Docker), `check_page` всё равно
проверит по коду: h1, alt, внешние и битые ссылки, фиксированные ширины,
парность тегов — и честно отметит, что прокрутку и консоль увидит только браузер.

## Сдача
Короткое и понятное имя: `Лендинг.html`, `Отчёт-презентация.html`, `Дашборд марта.html`.
Расширение `.html` — в конце имени и видимое. В ответе: имя файла одной строкой,
что открывается во вкладке, и что видно на снимке 390 px. Файл и снимки уже лежат
в «Файлах проекта» — снимок и есть доказательство, что страница живая.
