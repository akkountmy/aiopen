# Веб-страница (.html)

## Когда открывать
«Сделай лендинг», «страницу», «одностраничный сайт», «интерактивный отчёт»,
«дашборд на HTML». Файл `.html` открывается у пользователя во вкладке браузера.

## Инструмент
`write_file({ path: "Страница.html", content })` — первая часть до ~8 КБ, затем
`append_file` остальными частями. Внешние CSS/JS не нужны: всё в одном файле.

## Анатомия страницы, которая выглядит дорого
1. `<!doctype html>`, `lang="ru"`, `meta viewport`, `charset`.
2. Секция hero: заголовок-утверждение, подзаголовок в одну строку, одно действие.
3. 3–6 смысловых блоков: текст + визуальный акцент (таблица, карточки, цифры).
4. Один блок с числами (2–4 KPI).
5. Финал: короткий вывод и контакт/действие.
6. Подвал: кто и когда сделал.

## Стиль без библиотек
```css
:root{--bg:#0b0d12;--panel:#141926;--text:#e8eaf0;--muted:#9aa4b8;--accent:#5b8cff}
*{box-sizing:border-box}
body{margin:0;background:var(--bg);color:var(--text);font:16px/1.6 system-ui,-apple-system,"Segoe UI",sans-serif}
.wrap{max-width:1080px;margin:0 auto;padding:0 24px}
h1{font-size:clamp(28px,4vw,52px);line-height:1.1;letter-spacing:-.02em;margin:0 0 16px}
.lead{color:var(--muted);font-size:clamp(16px,1.6vw,20px);max-width:60ch}
.grid{display:grid;gap:20px;grid-template-columns:repeat(auto-fit,minmax(220px,1fr))}
.card{background:var(--panel);border:1px solid #222a3a;border-radius:14px;padding:20px}
@media (max-width:640px){.wrap{padding:0 16px}}
```
- Одна акцентная палитра: фон тёмный, панели светлее фона, акцент один.
- Шрифт — системный стек. Никаких Google Fonts: офлайн и приватность.
- Отступы кратны 8 px; вертикальный ритм важнее украшений.
- Адаптивность: `auto-fit/minmax`, `clamp()` для заголовков, проверка на 360 px.
- Не больше двух весов шрифта и одного акцентного цвета.

## Интерактив без фреймворков
- Переключение таб/аккордеон — пара строк на `addEventListener` + `classList.toggle`.
- Графики — inline `SVG` (прямоугольники/линии) или `canvas`; библиотеки не подключай.
- 3D — только через навык `three-js` и локальный `/vendor/three.global.js`.
- Никаких `fetch` к внешним API: страница живёт локально и должна работать без сети.

## Проверка перед сдачей (браузера нет, поэтому проверяй глазами по коду)
1. Файл `.html`, открывается одной вкладкой, без внешних запросов.
2. Все теги закрыты; нет битых кавычек в атрибутах.
3. Мобильная ширина: нет фиксированных `width: 1200px` без `max-width`.
4. Текст не выходит за `max-width: 60ch` — читаемость.
5. Есть `window.onerror` → видимая плашка с текстом ошибки (пользователь пришлёт её, если что-то упало).
6. Скажи пользователю имя файла и что откроется во вкладке.
