# Правовое заключение / карта правовых рисков

Две формы в одном файле: короткая карта рисков для рабочего договора и полное заключение для сделки. Нужная часть заполняется, остальная удаляется — но допущения и оговорки остаются всегда.

## Форма Б. Правовое заключение

### 1. Вопрос

Один вопрос, на который нужен ответ, и решение, для которого он нужен.

### 2. Факты и документы

| Документ | Дата | Что из него следует |
|---|---|---|
|  |  |  |

### 3. Применимые нормы

| Норма | Что регулирует | Как применяем |
|---|---|---|
|  |  |  |

### 4. Анализ

Квалификация отношений, толкование условий, практика, неоднозначности. Для каждой неоднозначности — оба прочтения и последствие выбора.

### 5. Вывод

Ответ на вопрос из п. 1, с вероятностью и последствиями: «сделка действительна при условии…», «риск оспаривания высокий, потому что…».

### 6. Допущения и оговорки

| Допущение | Что будет, если оно неверно |
|---|---|
|  |  |

Что не проверялось: иностранное право, налоговые последствия, судебная практика после даты, документы вне списка.

### 7. Что должен проверить юрист перед подписью

Список конкретных пунктов и норм с указанием источника проверки.
