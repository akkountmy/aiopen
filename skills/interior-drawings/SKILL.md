# Чертежи интерьера: SVG, PDF, 3D из одного спека

Все выходы строятся из **одного JSON-спека помещения** — правка в одном месте меняет
план, развёртку, аксонометрию и 3D. Скрипты лежат рядом: `scripts/`, примеры — `examples/`.

```
scripts/lib.mjs        общая библиотека: листы/рамка/штамп, масштаб, каталог мебели, размерные цепочки
scripts/plan.mjs       план: --mode=plan|floor|ceiling
scripts/elevation.mjs  развёртка стены (длина × высота, зоны отделки, проёмы, мебель, выноски)
scripts/axo.mjs        аксонометрия 30°, стены срезаны на 1150 мм
scripts/scene.mjs      интерактивная 3D-сцена (three.js локально, без CDN)
scripts/render.mjs     SVG/HTML → PDF/PNG через Edge или Chrome
scripts/shot.mjs       скриншот HTML через Playwright Chromium (для WebGL)
```

## Быстрый старт

```bash
cd <папка навыка>
node scripts/plan.mjs examples/квартира-44.json out/план.svg --mode=plan
node scripts/plan.mjs examples/квартира-44.json out/полы.svg --mode=floor
node scripts/plan.mjs examples/квартира-44.json out/потолок.svg --mode=ceiling
node scripts/render.mjs out/план.svg out/план.pdf --png out/план.png
node scripts/elevation.mjs examples/развёртка-кухня.json out/развёртка.svg
node scripts/axo.mjs examples/квартира-44.json out/аксонометрия.svg
node scripts/scene.mjs examples/квартира-44.json out/3d.html
node scripts/shot.mjs out/3d.html out/3d.png --width 1600 --height 1000
```

Каждый CLI печатает JSON с результатом (`out`, `scale`, `bytes`, `totalArea`) — это
признак «сделано», не «запущено».

## Схема спека

Координаты в **миллиметрах**, ось Y вниз (как на плане), начало — в левом верхнем углу
габарита. Полигоны комнат — по внутренним граням стен.

```json
{
  "project": "Квартира 44,1 м² — интерьер с нуля",
  "object": "Минск, ул. Примерная, 12, кв. 45",
  "scale": 50,
  "sheet": "A3",
  "heights": { "wall": 2700, "ceiling": 2650 },
  "cut": 1150,
  "rooms": [
    { "name": "Кухня-гостиная", "poly": [[200,200],[4550,200],[4550,5800],[200,5800]],
      "floor": "инженерная доска", "tile": 0, "ceiling": "натяжной" }
  ],
  "walls": [
    { "x1": 0, "y1": 0, "x2": 8000, "y2": 0, "t": 200 }
  ],
  "openings": [
    { "kind": "window", "x": 1500, "y": 0, "w": 1800, "dir": "h", "sill": 900, "h": 1500 },
    { "kind": "door", "x": 4750, "y": 4800, "w": 900, "dir": "v", "hinge": "right", "swing": "in" }
  ],
  "furniture": [
    { "kind": "sofa", "x": 400, "y": 4300, "w": 2200, "d": 950, "rot": 0, "name": "Диван" }
  ],
  "fixtures": [
    { "kind": "spot", "x": 1200, "y": 900 },
    { "kind": "chandelier", "x": 2400, "y": 3000 },
    { "kind": "led", "x": 400, "y": 200, "w": 2000 }
  ],
  "notes": ["Все размеры в миллиметрах, высота потолка 2700."]
}
```

- `walls` — ось + толщина `t`; горизонтальная стена = равные `y1`,`y2`, вертикальная — равные `x1`,`x2`.
- `openings.dir` = `h` для горизонтальной стены, `v` для вертикальной; `x`,`y` — привязка
  к оси стены. Окно: `sill` + `h`; дверь: `h` (2100 по умолчанию), `hinge` = `left|right`, `swing` = `in|out`.
- `furniture.kind` — из каталога `CATALOG` в `lib.mjs` (sofa, sofa_corner, armchair, bed_double,
  bed_single, wardrobe, wardrobe_slide, shelving, tv_stand, kitchen_counter, fridge, hob, sink,
  bath, shower, wc, bath_sink, dining_table, coffee_table, desk, chair, rug). Если габарит не
  задан (`w`,`d`,`h`), берётся каталожный; `rot` — поворот в градусах вокруг центра.
- `fixtures.kind` = `spot|chandelier|led` — для `--mode=ceiling` (точечный, люстра, лента).

## Режимы плана

| `--mode` | Что на листе |
|---|---|
| `plan` | стены, проёмы, мебель, подписи комнат с площадью, экспликация, размерные цепочки |
| `floor` | раскладка пола по комнатам, сетка плитки (`tile` мм), ведомость полов |
| `ceiling` | уровни потолка, светильники в плане, список «СВЕТИЛЬНИКИ» с количеством |

## Листы, масштабы, линии

- Форматы `A4|A3|A2|A1` (книжная/альбомная — по `sheet`), рамка по ГОСТ 2.301:
  слева 20 мм, справа/сверху/снизу 5 мм; штамп 150×45 в правом нижнем углу.
- Масштаб подбирается автоматически из `1:20/25/50/75/100` так, чтобы чертёж занял поле
  листа; в штампе и в выводе CLI печатается фактический (`scaleText`).
- Толщины: контур стен 0.7, перегородки 0.5, мебель 0.35, размерные/выносные 0.18–0.25,
  осевые 0.15. Штриховка отделки — паттерны из `defs()` (плитка, доска, гипс, утеплитель).
- Текст: подписи комнат с белым «гало» (читаются поверх мебели), длинные подписи усекаются
  по ширине блока с многоточием, десятичные — через запятую (`num()`).

## Развёртка (`elevation.mjs`)

Спек отдельный: `{project, object, wall: {name, length, height, baseboard, finishes[],
openings[], furniture[], callouts[]}}`. `finishes` — зоны по высоте (`from`/`to` в мм,
`hatch` из `defs()`, `label`); `callouts` — кружки с номером и текстом материала.
Масштаб 1:20–1:50 автоматически, слева высотные отметки, снизу размерная цепочка.

## Аксонометрия (`axo.mjs`)

Изометрия 30°: `(x + y)·sin30` по горизонтали, `z` по вертикали; стены режутся на
`spec.cut ?? 1150` мм, чтобы видеть мебель. Комнаты подписаны с площадью, есть примечание
о срезе и высоте помещения.

## 3D (`scene.mjs` + `shot.mjs`)

`scene.mjs` собирает один HTML-файл и копирует рядом `three.global.js` (из
`~/.dsh/vendor/three/dist/`), поэтому страница работает офлайн, без CDN. Что внутри:
пол по полигонам комнат с цветом материала, стены с реальными проёмами (подоконная часть +
перемычка), стекло окон, мебель блоками с рёбрами, подписи комнат спрайтами, орбитальная
камера (ЛКМ — поворот, колесо — масштаб, ПКМ — сдвиг), виды `План / Угол 1 / Угол 2 / Кухня`,
переключатели `Потолок` и `Срез стен` (стены обрезаются на `cut`).

`shot.mjs` снимает PNG через Playwright Chromium (`playwright-core` ищется в
`./node_modules`, в DSH.OPEN.WEB и в `~/.dsh`). Для статичного кадра страница открывается
с `?shot=1` — после 4-го кадра цикл рендера останавливается.

## Самопроверка перед сдачей

1. `plan.mjs` печатает `totalArea` — сверьте с обмером (±2 %).
2. Открыть PDF/PNG и проверить глазами: подписи не наезжают, размеры читаются, штамп на месте.
3. Проёмы на плане совпадают со стенами (окно не «висит» в воздухе).
4. Комната без мебели в проходе шириной < 600 мм — переставить.
5. Аксонометрия: стены не закрывают интерьер (иначе уменьшить `cut`).
6. 3D: мебель на полу, а не в стене; двери/окна на своих местах; в консоли нет ошибок.

## Грабли (проверено)

- `sheet.area` возвращает ключи `x/y/w/h` (не `x0/y0`) — перепутали, получите `NaN` и
  чертёж за листом.
- PowerShell `Set-Content -Encoding utf8` добавляет BOM → `JSON.parse` падает на `\uFEFF`.
  Пишите JSON из Node/Python, а скрипты уже терпят BOM.
- Headless Edge на машинах без GPU отдаёт **пустой** кадр WebGL (PNG валидный, но белый).
  Для 3D снимайте `shot.mjs` (Chromium + SwiftShader), а не `render.mjs`.
- `render.mjs` требует установленный Edge/Chrome; путь можно задать `EDGE_PATH`.
- SVG в PNG: страница получает `svg{width:100vw;height:100vh}`, иначе снимется только
  левый верхний угол.
